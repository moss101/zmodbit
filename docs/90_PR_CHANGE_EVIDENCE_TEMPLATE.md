# PR / Change Evidence Template

## Requirements

`REQ-*`, `REQ-EV-*`, task IDs.

## Existing behavior

Trace and classification before this change.

## Change

What production behavior changed and which canonical owner was modified.

## Architecture

Confirm no new parallel owner/system. List ADR if architecture changed.

## Security/effects

Capabilities, protected effects, secret/path/network implications.

## Persistence/recovery

Schema/migration, replay, idempotency and restart implications.

## Tests

Commands + results for unit/property/integration/qualification/E2E/security/performance as applicable.

## Real-system evidence

Run IDs, event/effect/artifact refs, screenshots only as supplemental evidence, not sole proof.

## Failure tests

Fault/negative cases exercised.

## Rollback

Code/schema/feature rollback plan.

## Remaining work

Must be empty for a COMPLETE task; otherwise status is partial/blocked.
